# Three-minute demo script

1. Run the training command and show the metrics and model card.
2. Start FastAPI and open `/docs` to demonstrate the health, prediction and drift contracts.
3. Send one synthetic applicant and explain the threshold as a review signal, not an automatic decision.
4. Open the monitoring code and explain PSI, model versioning, rollback and retraining triggers.
5. Close with the governance controls required before any real financial deployment.
